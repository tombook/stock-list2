# v0.2 — Vectorized Backtester + Analyze Page

**Date:** 2026-07-23
**Status:** Awaiting user review
**Milestone:** ROADMAP.md "v0.2 one good backtester" + the Analyze-page slice of v0.3 (pulled forward so the UI can exercise the agent that already works).

## Goal

Ship two things end to end:

1. A single vectorized backtester (pandas/numpy) with `POST /api/backtest` and a
   `run_backtest` agent tool.
2. A frontend Analyze page: chat box + SSE streaming renderer (`step`/`tool_call`/
   `tool_result`/`final`/`error`/`done`) so the UI can drive the agent that already
   works at `POST /api/analyze`.

## Non-goals (out of scope for this spec)

- Persistence (watchlist/runs tables, Alembic). Still v0.3.
- Short positions, fractional sizing, multi-asset portfolios, slippage modeling.
- Backtest result charting on the frontend (the API returns an equity curve; a
  chart component is a separate milestone).
- Auth, multi-user, run history.

## Decisions (locked)

| Decision | Choice | Rationale |
|---|---|---|
| Position side | **Long-only**, signal ∈ {0,1} | Smaller test surface; matches retail-equity use. Add short later. |
| Strategy interface | Pure function `(bars_df, **params) -> pd.Series[int]` | Testable in isolation; vectorized; trivially registry-dispatched. |
| Execution model | Signal at bar `t` known at close → position held from `t+1` | No lookahead. `position = signal.shift(1).fillna(0)`. |
| Returns | `position * asset_pct_change − trade_cost`; equity compounded | Standard vectorized form. |
| Cost model | `cost_bps` (basis points) per unit of position change, **default 0** | Frictionless by default; agent/caller can pass it. |
| Annualization | periods/year mapped from timeframe (252/52/12/etc.) | Timeframe-aware CAGR/Sharpe. |
| Built-in strategies | `sma_cross`, `momentum`, `buy_hold` (parameterized) | Covers trend/momentum/baseline; small enough to test exhaustively. |
| `run_backtest` tool → LLM payload | **Metrics only** (no equity array) | Saves LLM tokens; UI fetches curve separately when needed. |
| Frontend SSE transport | `fetch` + `ReadableStream` + `TextDecoder` | POST body required → `EventSource` can't be used. |
| Frontend state | Dedicated `analyzeStore` (zustand) | Matches existing pattern (`marketStore`). |

## Backend design — `backend/app/backtest/`

One responsibility per file, each <300 LOC. Depends on `app.core` and
`app.marketdata.service` only.

### `strategies.py` (~70 LOC)

Pure functions + a registry.

```python
def sma_cross(bars: pd.DataFrame, *, fast: int = 5, slow: int = 20) -> pd.Series: ...
def momentum(bars: pd.DataFrame, *, lookback: int = 20) -> pd.Series: ...
def buy_hold(bars: pd.DataFrame) -> pd.Series: ...

# Registry: name -> (fn, default_params, json_schema_for_params)
STRATEGIES: dict[str, StrategySpec]
```

- Each strategy returns a `pd.Series[int]` of {0,1}, index aligned with `bars.index`.
- `sma_cross`: 1 when `SMA(fast) > SMA(slow)`, else 0. Needs `slow` bars warmup;
  early values = 0.
- `momentum`: 1 when `close[t] > close[t-lookback]`, else 0. Warmup = `lookback`.
- `buy_hold`: always 1 from the first bar.

### `metrics.py` (~70 LOC)

Pure numpy/pandas functions on a strategy's returns/equity.

```python
def periods_per_year(timeframe: str) -> int: ...
def total_return(equity: pd.Series) -> float: ...
def cagr(equity: pd.Series, periods_per_year: int) -> float: ...
def sharpe(returns: pd.Series, periods_per_year: int) -> float: ...
def max_drawdown(equity: pd.Series) -> float: ...
def win_rate(bars: pd.DataFrame, position: pd.Series) -> tuple[float, int]:
    # returns (win_rate, n_closed_trades)
```

- `periods_per_year` mapping: `1d→252`, `1wk→52`, `1mo→12`, `1h→252*6.5`,
  `30m→252*13`, `15m→252*26`, `5m→252*78`, `1m→252*390`. Unknown → 252.
- Sharpe assumes risk-free = 0; `mean/std * sqrt(periods_per_year)`. std=0 → 0.0.
- `win_rate`: identify entry/exit pairs from `position` (0→1 entry at bar t,
  1→0 exit at bar t'). Pnl per closed trade = `close[exit]/close[entry] - 1`.
  Open positions ignored. Returns 0.0 when no closed trades.

### `engine.py` (~80 LOC)

The single vectorized simulator.

```python
@dataclass(frozen=True)
class EngineResult:
    position: pd.Series       # realized position (signal shifted, no lookahead)
    asset_returns: pd.Series
    strategy_returns: pd.Series
    equity: pd.Series         # compounded, starts at 1.0
    n_entries: int            # 0→1 transitions
    n_closed_trades: int      # entries that subsequently exited (0→1→0)

def run(bars: pd.DataFrame, signal: pd.Series, *, cost_bps: float = 0.0) -> EngineResult:
    ...
```

Algorithm:

```
position      = signal.shift(1).fillna(0).astype(int)   # position[0]=0 always
asset_returns = bars["close"].pct_change().fillna(0.0)
turnover      = position.diff().abs().fillna(position.abs())
trade_cost    = (cost_bps * 1e-4) * turnover
strategy_ret  = position * asset_returns − trade_cost
equity        = (1 + strategy_ret).cumprod()
entries       = (position.diff() == 1)
n_entries     = int(entries.sum())
n_closed      = count of 0→1→0 round trips (entries that exited before the last bar)
```

**No-lookahead invariant:** for `t ≥ 1`, `position[t] == signal[t-1]`; `position[0] == 0`
regardless of `signal[0]`. The engine test asserts this for `t ≥ 1` on synthetic data.

### `schemas.py` (~60 LOC)

Pydantic v2 request/response.

```python
class StrategyRef(BaseModel):
    name: str
    params: dict[str, int | float | str] = {}

class BacktestRequest(BaseModel):
    symbol: str
    strategy: StrategyRef
    timeframe: str = "1d"
    limit: int = 252          # 50 ≤ limit ≤ 1000
    cost_bps: float = 0.0     # ≥ 0

class Metrics(BaseModel):
    total_return: float
    cagr: float
    sharpe: float
    max_drawdown: float
    win_rate: float
    n_trades: int

class EquityPoint(BaseModel):
    ts: datetime
    equity: float

class BacktestResponse(BaseModel):
    symbol: str
    strategy: StrategyRef
    timeframe: str
    n_bars: int
    start: datetime
    end: datetime
    metrics: Metrics
    equity: list[EquityPoint]
```

Validators: `limit` must be in [50, 1000] (else `DomainError` → HTTP 400, no silent
clamping); `cost_bps` ≥ 0; strategy name must exist in registry (else
`NotFoundError` → HTTP 404).

### `service.py` (~50 LOC)

Single public async entry.

```python
async def run_backtest(req: BacktestRequest) -> BacktestResponse:
    bars = await market_service.get_bars(req.symbol, req.timeframe, req.limit)
    df   = to_dataframe(bars)               # pure conversion
    result = await asyncio.to_thread(_run_sync, df, req)
    return _to_response(result, req, bars)
```

- `to_dataframe` converts the typed `Bars` pydantic model to a `pd.DataFrame`
  (one-liner; lives in `service.py`).
- Heavy work offloaded via `asyncio.to_thread` per the AGENTS.md async rule.
- Exceptions raised inside `to_thread` (e.g. strategy param errors like `slow <= fast`,
  unknown strategy name, NaN in close) are caught and re-raised as `DomainError`
  (or `NotFoundError` for unknown strategy) so `app.core.errors` can map them to HTTP.
- Strategy lookup raises `NotFoundError` for unknown name; malformed params raise
  `DomainError` (mapped to HTTP in `app.core.errors`).
- The response's `metrics.n_trades` is the engine's `n_closed_trades` (round-trip count,
  matching the `win_rate` denominator). `n_entries` is exposed on `EngineResult` for
  debugging/tests but not surfaced in the API.

## API — `backend/app/api/backtest.py` (~30 LOC)

```python
POST /api/backtest
body: BacktestRequest
→ BacktestResponse   (200)  | NotFoundError (404) | DomainError (400)
```

Thin router; calls `backtest.service.run_backtest` only. Wired into
`app/main.py` alongside the existing routers.

## Agent tool — extends `backend/app/agent/tools.py`

New entry in `registry()`:

- **name:** `run_backtest`
- **description:** "Run a backtest of a named strategy on a market symbol and
  return performance metrics."
- **parameters:** same shape as `BacktestRequest` (so the LLM uses one mental
  model for the tool and the API).
- **handler result:** **metrics only**, no equity array. Shape:

  ```json
  {
    "symbol": "AAPL", "strategy": "sma_cross", "timeframe": "1d",
    "n_bars": 252, "start": "...", "end": "...",
    "total_return": 0.12, "cagr": 0.12, "sharpe": 0.9,
    "max_drawdown": -0.18, "win_rate": 0.55, "n_trades": 6
  }
  ```

The handler builds a `BacktestRequest`, calls `backtest.service.run_backtest`,
drops `equity`, flattens `metrics` into the top level. Tool failures (e.g.
unknown strategy) flow through the existing loop error path
(`{"error": "..."}`) so the LLM can recover.

## Frontend design

### Routing & nav

- New route `/analyze` in `routes.tsx`; new page `pages/AnalyzePage.tsx`.
- New nav entry "Analyze" with `MessageSquare` icon in `BasicLayout.tsx`.

### `api/analyze.ts` (~70 LOC)

```ts
export interface AnalyzeEventHandlers {
  onStep?(index: number): void;
  onToolCall?(id: string, name: string, args: unknown): void;
  onToolResult?(id: string, name: string, ok: boolean, result: unknown): void;
  onFinal?(answer: string): void;
  onError?(message: string): void;
  onDone?(): void;
}

export async function streamAnalyze(
  prompt: string,
  handlers: AnalyzeEventHandlers,
  signal?: AbortSignal,
): Promise<void>;
```

Implementation: `fetch("/api/analyze", {method:"POST", body, signal})`, read
`response.body` via `getReader()`, accumulate into a string buffer, split on
`\n\n`, parse `event:` and `data:` lines, dispatch to handlers. No `EventSource`
(POST body unsupported).

### `stores/analyzeStore.ts` (~80 LOC)

```ts
interface ToolCall { kind: "tool"; id: string; name: string; args: unknown; result?: unknown; ok?: boolean }
interface UserMsg  { kind: "user"; text: string }
interface AsstMsg   { kind: "assistant"; text: string; error?: boolean }
type Message = UserMsg | AsstMsg | ToolCall;

interface AnalyzeState {
  messages: Message[];
  isStreaming: boolean;
  step: number | null;
  send(prompt: string): Promise<void>;
  abort(): void;
  reset(): void;
}
```

- `send` pushes a user message, sets `isStreaming`, calls `streamAnalyze` with
  handlers that mutate state (tool_call → push ToolCall, tool_result → patch the
  matching ToolCall by id, step → set `step`, final → push assistant message,
  error → push assistant `error` message + sonner toast, done → clear flags).
- Holds an `AbortController` for `abort()`.

### `pages/AnalyzePage.tsx` (~120 LOC)

- Sticky input box (textarea + send button). Enter to send; Shift+Enter newline.
- Scrollable message list above. Auto-scroll to bottom on new message.
- Renderers:
  - `user` → right-aligned bubble.
  - `assistant` → left-aligned bubble, markdown via `react-markdown` (add dep).
  - `tool` → card: tool name (mono), args as pretty JSON, result collapsible
    (default collapsed if > 200 chars).
  - `step` → thin "Step N" divider while streaming.
- Empty state: a couple of suggested-prompt chips ("Analyze AAPL",
  "Backtest SMA cross on MSFT daily").

### New dependency

- `react-markdown` for the assistant bubble. Lightweight, framework-agnostic.

## Tests

### Backend (`backend/tests/`)

- `backtest/test_metrics.py` — each metric on hand-computed arrays (known
  return series, known equity, zero-variance Sharpe edge case, no-closed-trades
  win rate).
- `backtest/test_engine.py` — deterministic 10-bar synthetic frame: (a) no
  cost → equity matches `(1+ret).cumprod()` of shifted signal; (b) cost_bps>0
  reduces equity on turnover; (c) no-lookahead invariant
  (`position[t] == signal[t-1]`).
- `backtest/test_strategies.py` — each strategy on synthetic trending/flat
  frames; warmup behavior; signal ∈ {0,1}.
- `backtest/test_service.py` — `market_service.get_bars` mocked; round-trip
  request → response shape; unknown strategy → `NotFoundError`; bad params →
  `DomainError`.
- `api/test_backtest.py` — endpoint with service mocked; happy path 200;
  unknown strategy 404; bad params 400.
- `agent/test_run_backtest_tool.py` — tool handler with service mocked; returns
  metrics-only shape (no `equity` key).

### Frontend (`frontend/src/`)
